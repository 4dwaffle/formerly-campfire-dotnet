## Actual operational differences and unverified branches

- No Redis configuration uses a single-process development fallback. Deployment config requires Redis. Original ready jobs/Cable wire are compatible; custom reserved, held and delayed jobs require a .NET worker. At-least-once recovery can duplicate side effects. Original application jobs have no automatic retry; this remains true.
- Port room jobs await the50-slot delivery pool before acknowledgement rather than abandoning ownership to Ruby's volatile50-worker/10000-pending pool. The original pool-cap rejection is not reproduced. Explicit delivery=false is a fixture/operator override absent from original Rails.
- Public document/push clients avoid environment proxies for checked-IP pinning; administrative webhooks permit them. Initial webhook headers use a combined seven-second connection/header budget rather than independent Ruby open/read budgets; body idle deadlines match. Push total60-second and native analysis30/transform45-second budgets differ from original phase/unbounded subprocess behavior.
- Ruby image_processing composite and metadata setter helpers are not all implemented by generic operation dispatch. Animated/multipage files, every encoder/loader and all signed operation combinations are not proven equivalent. Missing processors do not return fabricated images. Poppler/MuPDF are optional exactly as previewer availability requires; default deployment matches the pinned image's missing PDF tools.
- Owner commit followed by disk publication failure preserves `.pending` bytes, but there is no automatic finalizer after a process dies between commit and publication. Original owner/after-commit separation has the same timing boundary; the port's retention prevents deletion of committed bytes but does not prove crash recovery.
- Storage is the pinned local disk service; mirror jobs are no-ops for that service. Cloud/mirrored storage configurations, credentials-file decryption fallback, external push providers and public unfurl sites are not implemented/verified by this deployment.
- Complete rendering/helper byte parity, cache-front conditional/range matrix, every UserAgent/Nokogiri malformed encoding branch, slow consumer overflow and native process crash/codec matrices remain unverified. Local passes and limited native paths are not substitutes for these checks.
